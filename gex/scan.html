After a scan, Claude reads the top-ranked names through the same rubric as the dashboard and returns a structured take. Costs a few cents per read (cached); educational only, not advice.

Vol-mispricing rank = a heuristic on the price of convexity (vol risk premium, term slope, 25Δ wings and the convexity read), each expressed as a fraction of the name's own implied vol so a 15-vol index and a 60-vol single name rank on the same footing. It leans rich (implied rich vs realized — a sell-premium tilt) or cheap (own convexity). Gamma columns are shown for context and never affect the rank.
